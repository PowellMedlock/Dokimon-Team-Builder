# Dokimon-Team-Builder
 A teambuilder for Dokimon Quest

## Requirements

Springboot 4.0

Java 21+

Maven 3.8.7

Node.js 20+

React 19+

Vite 7+

### The app was made using these versions:

Springboot 4.0

Java 21.0.12

Maven 3.8.7

Node.js 24.20.0

Vite 7.1.3

the Spring Boot backend running on port 8080.
the React frontend running on port 5173.

Jetbrains Webstorm was used to run the app.

## Running

```bash
npm install
npm run dev
```

will run the entire project, then put

```
http://localhost:5173
```

into your browser.
